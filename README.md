# Ranger Mk1
Public repository with Firmware, SW tools and guides for the AceHigh Ranger-Mk1 Module

## Introduction
The Ranger module enables smart distributed actuators for applications that require mechanical motion.
Building on engineering experience from the space industry, the Ranger targets industrial, robotics and aerospace applications, but really if you need a reliable actuator controll solution - Ranger might be just what you need.

The Ranger module combines modern stepper motor driver circuits, encoder and sensors together with a robuste CAN interface to form a actuator node solution, built to fit the NEMA 14, 17 and 23 standard stepper motors.
